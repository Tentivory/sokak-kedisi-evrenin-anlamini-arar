# Sokak Kedisi Evrenin Anlamını Arar

## Resmi ve Çok Ciddi Açıklama

Bu repository, insanlığın en büyük sorularından birine cevap arayan bir sokak kedisinin zihinsel yolculuğunu simüle eder. 

**Neden var?** Çünkü bir kedi neden olmasın? Evren anlam arıyor, kedi de arar. Adalet bu.

### Nasıl Çalıştırılır?

```bash
python3 kedinin_arayisi.py
```

Kod gerçekten çalışır. Bekleyin. Kediler acele etmez. Siz de etmeyin.

### Özellikler

- Yavaş düşünme (time.sleep ile onaylandı)
- Rastgele felsefi miyavlar
- Sıfır kalori
- Gerçek kedi içermez (hayvan hakları korunur)

### Uyarı

Bu kodu çalıştırdıktan sonra hayata bakışınız değişebilir. Veya değişmeyebilir. Kedi bile emin değil.
